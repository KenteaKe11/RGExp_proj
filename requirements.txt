# ── TRẦN 4.53 LÀ CÓ CHỦ Ý, ĐỪNG NỚI ─────────────────────────────────────────
# Từ 4.53, transformers dựng mask ảnh hai chiều của Gemma 3 bằng
# `or_mask_function`, và cái đó đòi torch >= 2.6. Ảnh pytorch/* trên máy thuê
# thường đứng ở torch 2.5.x -> MỌI ảnh ném
#     ValueError: Using `or_mask_function` ... require torch>=2.6
# Một lần chạy đã chết đúng như thế: 3000 ảnh × 3 model, mỗi ảnh một lỗi, và vì
# tầng chống lỗi ghi chuỗi rỗng để đi tiếp, pipeline kết thúc "thành công" với
# bảng điểm toàn số 0.
#
# Ghim ở đây rẻ hơn nhiều so với nâng torch (vài chục MB so với ~2.5 GB) và giữ
# nguyên bản torch vốn đã khớp CUDA của máy. Khoảng 4.51-4.52 thoả CẢ BA model:
#   Gemma 3            cần >= 4.50
#   Qwen2.5-VL         cần >= 4.49
#   Phi-3.5-vision     remote code import `_prepare_4d_causal_attention_mask`,
#                      hàm bị bỏ trong đợt tái cấu trúc mask của bản mới hơn
# Muốn dùng transformers mới hơn thì phải nâng torch >= 2.6 TRƯỚC, và bỏ Phi
